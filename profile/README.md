## Lilly and Othersについて

**Lilly and Others**は、上位存在を描くことを中心に、ゲームやその他の創作をつくるサークルです。

小さなアイデアを形にしながら、遊んだ人の記憶に残る作品をつくっています。

## つくっているもの

| 分野 | 取り組み |
| --- | --- |
| 👁 上位存在 | 私たちの創作の中心にある主題 |
| 🎮 ゲーム | 実験作、プロトタイプ、完成作品 |
| 🧩 ツール | 創作を支える小さな道具や仕組み |
| ✦ その他の創作 | 物語、世界、さまざまな表現 |

## 現在の活動

上位存在を描く作品と制作記録は、Organization内の各リポジトリで進行しています。
公開できる作品やリリースは、順次ここから案内していきます。
